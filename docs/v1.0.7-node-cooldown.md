# BF4BR v1.0.7 node-wide Battlelog cooldown

All BF4BR persona and report processes on one host share an exclusive flock and cooldown state at `/tmp/bf4br-battlelog-cooldown.json`. A Battlelog HTTP 429 stops new requests from that host for at least 120 seconds, or longer if a valid `Retry-After` header specifies it. Other hosts are unaffected. The 429 response and `Retry-After` value are recorded in the worker journal. Supervisors continue their existing heartbeat behavior.

The daily persona worker prioritizes eligible daily jobs and uses historical jobs for its assigned platform when no daily job is eligible. It checks daily eligibility again after completing each historical job.

The monitor source is in `website/monitor/`; the host-side snapshot scripts and systemd units are in `deploy/monitor/`. The running Apache site remains at `/var/www/html/battle-reports-live.php` on reports. Website release integration remains to be validated before the production release.
